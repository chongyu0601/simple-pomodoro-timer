# 随机名言生成器｜Vibe Coding 演示项目
## 项目用途
这是一个简单的前端网页工具，点击按钮可以随机展示一句经典名言，适合学习之余用来给自己打气。
## 设计思路
项目只用单个HTML文件，HTML搭建页面卡片结构，CSS美化页面样式，JavaScript实现随机抽取名言的逻辑。
没有引入外部框架、数据库，打开浏览器直接运行。
本次采用Vibe Coding方式开发：用自然语言描述需求，由AI生成代码，我测试功能、确认效果，满足课程提交要求。
## 使用方式
1. 下载 index.html
2. 双击文件，用浏览器打开
3. 点击按钮切换不同名言
